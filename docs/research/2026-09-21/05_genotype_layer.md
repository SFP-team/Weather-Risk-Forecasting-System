### 1b. Rule-based matching precedents
- **Safe Winter Chill** (Luedeling et al. 2009, https://pmc.ncbi.nlm.nih.gov/articles/PMC2707005; 2011, https://pmc.ncbi.nlm.nih.gov/articles/PMC3077742): chill available in 90 % of years vs cultivar requirement; cultivars above local SWC fail >10 % of years. chillR implements CH/Utah/CP and PLS phenology (https://eikeluedeling.r-universe.dev/chillR).
- UGA rule of thumb for bloom timing by chill class in S GA (200–300 h → mid–late Feb bloom; 400–500 → early–mid Mar; 600–800 → mid–late Mar) https://smallfruits.org/files/2019/06/06bbcvproc_Nov0206.pdf.
- HS1245 itself encodes region adaptation as a categorical prior (S-central / central / N-central / >Gainesville) — usable directly as a filter.
- MSU P1758 lists cultivars 'in increasing order of chilling requirement' and prescribes 300–400 h south of Hattiesburg, ≥500 h north — the same filter logic.

### 1c. Model path
- **UF data exists**: Adunola, Ferrão, Azevedo, Nunez, Munoz 2024, Euphytica 220:113 (https://doi.org/10.1007/s10681-024-03364-9): 24 genotypes × 4 FL mega-environments (Citra, Central-North, Central, South) × 5 seasons (2018–22), 21 environmental covariables, five fruit-quality traits; temporal windows of plasticity identified; EC-informed mixed model for G×E; Finlay–Wilkinson adaptability/stability. Also Adunola 2024 Plant Genome (GS training design) https://doi.org/10.1002/tpg2.20488, and de Bem Oliveira 2020 Heredity (tetraploid GBLUP) https://doi.org/10.1038/s41437-020-00357-x. Pedigree/genomic relationship matrices exist in the program (Diego) [inferred from those papers, not seen].
- **Methods**: reaction-norm GBLUP with EC kernels — Jarquín et al. 2014 TAG 127:595 (https://doi.org/10.1007/s00122-013-2243-1); enviromics/EnvRtype — Costa-Neto et al. 2021 G3 (https://doi.org/10.1093/g3journal/jkab040); factorial regression / FW as in Adunola 2024; CGM-WGP (Technow et al. 2015 PLoS ONE https://doi.org/10.1371/journal.pone.0130855) if a phenology crop model is available — it is not for blueberry, so GBLUP+EC is the realistic path.
- **Minimal data**: Jarquín-type models need ECs to vary meaningfully across environments; with 4 mega-environments × 5 years = 20 environment-years the EC design is thin but usable for within-Florida ranking; extrapolation to Brazil requires ≥1 Brazilian trial-year or the model must be flagged as untested off-support (the R review already warns about this, R_FULL_CODE_REVIEW.md §Genotype).

## 2. Concrete recommendations

1. **`config/cultivars.json`** (new): one record per cultivar: `type`, `chill_h` {value, low, high, source, definition}, `bloom50_gainesville`, `harvest50_gainesville`, `system` ∈ {evergreen, deciduous, both}, `hc` ∈ {required, optional, harmful}, `region_prior` (HS1245 categories), `split` ∈ {high, mod, low, gap}, `disease_flags`[], `evidence` level. Every field carries a source URL; conflicts kept as ranges, not averaged. Non-FL/obsolete cultivars retained but flagged `recommended_fl=false`.
2. **`pipelines/weather/genotype_match.py`** (new), consuming the existing production.py per-site outputs:
   - Hard filters: (i) if site class = evergreen → `system ∈ {evergreen, both}`; (ii) else `chill_h.high ≤ p10 chill hours (0–7.2 °C band, AgroClimate-compatible)` — use the CH comparator, not CP, because no cultivar has a CP requirement; (iii) `recommended_fl` or user opt-in.
   - Score (0–1, weights exposed in config): bloom-timing exposure = fraction of winters with Tmin ≤ −2.2 °C inside the cultivar's bloom window (shift Gainesville bloom by site GDD offset, or use the existing class GDD targets from RISK_FACTOR_RESEARCH.md); split penalty = `split × harvest heavy-rain frequency`; disease penalty = flagged pathogen × disease-days frequency (only once disease days are ranked per Paul's decision 2); region prior bonus.
   - Output top 3–5 with the failing/passing rule per cultivar and an `evidence` tag; never a yield claim.
3. **`location_api.py`**: append `genotype_shortlist` to the `location-evidence-v3` payload (bump to v4); **`dist/app.js`**: panel listing shortlist with rule trace and 'assumption-based, not validated' banner.
4. **`production.py`**: replace the 50 h constant with the cultivar-class requirement from the same JSON so phenology and genotype layers cannot diverge (cross-topic: depends on the chill-method decision).
5. **Model path scaffold** (only after data arrive): `pipelines/genotype/enviromics.py` computes the 21 ECs (or the project's own ~35 metrics) per trial site-year from the NASA POWER archive; fit GBLUP+EC (reaction norm) in R (BGLR/EnvRtype) or Python; store per-genotype predicted trait means + SE per target environment in the CSV schema the R postprocessor already expects (predictions/SE/preferences/metadata). App reads predictions only.

## 4. Risks, unknowns, human decisions

- **Chill units mismatch**: cultivar requirements are in hours <7 °C (three conventions); site pipeline is moving to chill portions. Either match in the CH comparator band or ask UF for CP-equivalent requirements. Decision: Paul.
- **Grid bias**: NASA POWER undercounts chill 30–40 % at the deciduous end (RISK_FACTOR_RESEARCH.md); a hard filter on p10 chill will wrongly exclude 300 h cultivars at Waldo unless a bias variant is used.
- **No freeze/heat tolerance per cultivar** anywhere; bloom-timing proxy is the only defensible v1. Decision: accept proxy or request UF bloom-stage freeze observations.
- **Evergreen system chill**: 'impact of chill accumulation in evergreen production is still under debate' (GP19); the evergreen branch should not use chill at all.
- **Conflicting chill values** (Primadonna, Sweetcrisp, Magnus, Krewer): keep ranges; ask Patricio which to trust.
- **Model extrapolation**: 4 FL mega-environments cannot support Brazil predictions; must be labelled off-support.
- **IP/marketing**: FFSP pages are licensing material; cite but do not present as validated.
