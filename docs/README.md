## Product in one sentence

**Dual-horizon decision support for Florida blueberries:** operational freeze/disease/harvest alerts (0–10 days) plus probabilistic seasonal crop-risk outlooks (1–3 months)—not a deterministic 90-day daily weather calendar.

Greenfield. Proposal and docs complete; implementation not yet started.
